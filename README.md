# Five Seconds to Explain the Glass

One sentence: the excuse a house cat gives in the five seconds after knocking a glass off the table.

> It was hogging my sunbeam, blocking my view of the bird, and frankly it looked at me first.

`main.ts` (Node 22, stdlib only) writes the line to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`, validating it is 1-200 characters, a single line, and not only white space.
